# Free-body statics for reinforcement section loss in concrete discontinuity regions

Code and reference fields for recovering how much tie reinforcement a
deteriorating concrete discontinuity region has left, from strain measured on it.

## What this does

An inspection of a corroding tie returns strain; an assessment needs the
reinforcement section that remains. A discontinuity region has no valid plane
section and no single lever arm, so the sectional route that converts one into
the other is unavailable.

The method here poses the conversion as statics on a free body cut through the
member: the tie force that reconciles the measured strain with the reaction
moment. Written out, the identifying condition is

```
T(theta) = T_c + rho_tie * (1 - theta) * S = T_req
```

which is **affine in the section loss `theta`**. The remaining area is therefore
a root, not the minimizer of an objective, and it needs neither a mesh nor a
full-field measurement. There is no neural network anywhere in the method.

Two questions follow, and the code answers both:

- **Identifiability** — whether `theta` is recoverable at all is decided by the
  sensor plan and the reinforcement drawing, before any data exists.
- **Detection** — what section loss a given instrument can actually detect,
  under an error model that matches the instrument rather than a convenient one.

## Layout

The tree is the one the work was developed in, so the scripts are byte-identical
to those that produced the results. No paths were rewritten for release.

```text
oracle/     constant-strain triangle and Q4 solvers, cracked-membrane
            constitutive, displacement-controlled Newton; the generators
            for every reference field, and the .npz fields themselves
pinn/       the identification itself, the error studies, and every figure
            script; figstyle.py holds the shared figure style
figures/    cached results (.json, .npz) and the rendered figures
```

`pinn/figdata.py` computes and caches every plotted quantity to
`figures/figdata.npz`; the `make_*` scripts only draw.

## Reproducing

```sh
pip install -r requirements.txt
cd pinn

python figdata.py                  # recompute the cache everything draws from
python make_figures.py             # observable choice, field, reaction centroid, recovery
python sawtooth.py                 # the fiber reading and what it costs
python make_pod_figure.py          # detection under three error models
```

Individual results have their own entry points, each printing what it computes:

```sh
python recover_nodal.py               # recovery from the complete field
python gauge_length_noise.py          # what a bonded fiber's gauge length costs
python gauge_bias_decomposition.py    # which mechanism moves the bias
python detection_three_models.py      # all three detection curves, one stream
python model_family_calibration.py    # the constitutive-family term, calibrated
python calibration_floor.py           # when calibration helps, and when it does not
python spatial_calibration.py         # why a sound zone is not a baseline
python two_parameter.py               # two deteriorated zones, one cut each
python reliability.py                 # the reliability chain
```

Everything runs on CPU. The field generators in `oracle/` are the slow part;
the shipped `.npz` files let you skip them.

## Scripts needing data from the published sources

The study is also checked against four published test series. Those
measurements belong to their original authors and are **not redistributed
here** — they are already available from the sources below, which is where they
should be obtained and cited from. The scripts that read them are included
because they document exactly what was done with them, but each expects a
`data/` directory you populate yourself:

| Script | Source it reads |
|---|---|
| `pinn/make_halfjoint_figure.py` | Desnerck, Lees & Morley (2017), dataset `doi:10.17863/cam.13336`, CC BY 4.0 |
| `pinn/bimschas_extract.py`, `pinn/bimschas_digitisation_error.py` | Bimschas (2010), ETH Zurich, `doi:10.3929/ethz-a-006050338` |
| `pinn/make_specimens_figure.py` | all four series above plus Davis (2015), Queen's University, CC BY, and Davis, Hoult & Scott (2017), `doi:10.1016/j.engstruct.2017.03.013` |
| `pinn/wall_check.py` | the openly released fiber-instrumented wall element |

Everything in `oracle/` was generated by the code here, so no third-party
restriction applies to any of it.
